# Echo Score

O Echo Score é um site com a proposta de transformar hábitos sustentáveis em uma experiência de jogo. A página convida as pessoas a adotar pequenas atitudes em favor do planeta e acompanhar seu progresso.

## Sobre o site

Na página inicial, o visitante encontra uma apresentação do Echo Score, uma ilustração temática e uma seção que explica a ideia em três passos: escolher uma atitude sustentável, registrar a ação e conquistar emblemas.

A área do jogador apresenta os principais elementos da experiência:

- **Echo Score:** total de pontos de experiência (XP), nível e progresso até o próximo nível.
- **Missão diária:** desafio para completar três ações sustentáveis no dia.
- **Ações:** opções como caminhar ou pedalar, escolher uma refeição vegetal, economizar energia e reutilizar objetos.
- **Sequência:** indicação de dias seguidos de participação.
- **Conquistas:** emblemas associados ao registro da primeira ação e ao alcance de cinco e doze ações.
- **Conta:** interface para entrar ou criar uma conta.

## Identidade visual

O site usa uma identidade visual inspirada na natureza, com tons de verde, detalhes em cores vivas, elementos gráficos relacionados ao planeta e cartões para destacar pontuação, missões e ações. O layout também possui adaptações para telas menores.

## Tecnologias

A interface foi construída com HTML e CSS.

## Estado atual

O projeto contém a interface visual da página inicial, do painel e do formulário de conta. O login, o cadastro e os recursos de progresso ainda não estão conectados a uma aplicação Python; portanto, os elementos visuais não representam funcionalidades já operacionais.
